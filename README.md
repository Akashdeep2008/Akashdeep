# Towards Zero Waste Cities — CHE 110 Project Website

A responsive, editorial-style educational website for a CHE 110 Environmental Studies project on sustainable solid waste management and zero-waste cities.

## Features
- Modern responsive layout with desktop and mobile navigation
- Detailed sections on the project context, six waste streams, environmental impacts, waste hierarchy, practical solutions, AI/IoT applications, city implementation roadmap, Indian city case-study prompts, conclusion and citizen action
- Interactive waste-category selector with management guidance
- Interactive six-step action checklist and progress indicator
- Keyboard-accessible waste selector, mobile menu, reduced-motion support and skip navigation
- SEO description and semantic HTML structure

## Run locally
Open `index.html` in a modern browser. No build step, package manager, server, API key or database is required.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.
4. Wait for the deployment and open the GitHub Pages URL shown in the Pages settings.

## Images and typography
The page uses high-resolution image URLs from Unsplash and Google Fonts. Internet access is needed for those external images and fonts to load. Replace these URLs with properly licensed, locally stored photos if you need a fully offline version. Images are used as editorial photography rather than AI-style collages or poster graphics.

## Academic accuracy
The website uses the supplied CHE 110 report for its core subject framing. It does not invent performance statistics or claim that the case-study cities achieved specific figures. Verify current city-specific details with official municipal or government sources before adding numerical claims. Biomedical and hazardous waste must be managed through applicable authorized systems; this website is educational and does not replace local rules.
